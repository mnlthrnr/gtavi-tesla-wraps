# Prompt: Tesla Custom Wrap

Ersetze `[DESIGN]` durch dein gewünschtes Motiv, zum Beispiel „Jason & Lucia aus GTA VI“.

> Bitte erstelle einen neuen tesla-custom wrap (template in bild2) im [DESIGN]-Design. Verwende dafür das [DESIGN]-Design im Anhang (Bild 1). Behalte die transparency des template files bei. Halte das Finalbild < 1Mb

Benötigte Anhänge:

- **Bild 1:** das gewünschte Design als Referenzbild.
- **Bild 2:** das zum Tesla-Modell passende Wrap-Template mit Transparenz.
